    6|       |//!

    8|       |//! 1. Pass 1 (Sequential): Scan the data section to build chunk index
    9|       |//! 2. Pass 2 (Parallel): Process chunks concurrently using the built index
   10|       |//!
   11|       |//! # When to Use
   12|       |//!
   13|       |//! This reader is designed for large MCAP files (>1GB) without a summary section.
   14|       |//! For smaller files or files with a summary, use the sequential reader or
   15|       |//! the parallel reader with summary support instead.
   16|       |//!
   17|       |//! # Performance Characteristics
   18|       |//!
